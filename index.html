Neural Palette Quantization

Smart 8-bit PNG Quantization

Unlike primitive PNG compressors that degrade gradients into blotchy bands, PixelShrink analyzes alpha transparency channels and generates optimized 256-color palettes with customized Floyd-Steinberg dithering.

  • Full preservation of semi-transparent alpha dropshadows
  • 60-80% file size reduction with zero visible pixelation
  • Strips auxiliary ancillary chunks (gAMA, cHRM, sRGB)

PixelShrink REST API v3

Simple HTTP endpoints for programmatic image shrink, resize, and modern conversion.

POST https://api.pixelshrink.com/v3/shrink 
curl https://api.pixelshrink.com/v3/shrink \
  --user api:ps_live_89f0293b91a78e9 \
  --data-binary @unoptimized-banner.png \
  --header "X-Convert-To: webp" \
  --header "X-Resize-Width: 1280" \
  --header "X-Preserve-Exif: false" \
  --dump-header /dev/stdout
